### STEP 4: Install OWASP ZAP

**4.1 Download ZAP**
- Go to: https://www.zaproxy.org/download/
- Download "Windows (64) Installer"
- File size: ~300 MB

**4.2 Install ZAP**
- Run installer
- Click Next → Next → Install
- Wait for installation
- Launch OWASP ZAP

**4.3 Configure ZAP**
- When ZAP opens, select: "No, I do not want to persist this session"
- ZAP will run on localhost:8080
- Go to: Tools → Options → API
- Note the API Key (default: changeme)

## 🔧 COMMON ISSUES & SOLUTIONS

### Issue 1: "python is not recognized"
**Solution:**
- Reinstall Python
- Make sure to check "Add Python to PATH"
- Restart Command Prompt

### Issue 2: "pip is not recognized"
**Solution:**
```
python -m pip install --upgrade pip
```

### Issue 3: "Cannot connect to ZAP"
**Solution:**
- Make sure ZAP is running
- Check ZAP is on port 8080
- In ZAP: Tools → Options → Local Servers/Proxies
- Verify port is 8080

### Issue 4: "Module not found: zapv2"
**Solution:**
```
pip uninstall python-owasp-zap-v2.4
pip install python-owasp-zap-v2.4
```

### Issue 5: "Port 5000 already in use"
**Solution:**
- Close any program using port 5000
- Or change port in config.py:
  SERVER_CONFIG['port'] = 5001

### Issue 6: "Dashboard not loading"
**Solution:**
- Check if Flask is running: python app.py
- Try: http://127.0.0.1:5000
- Clear browser cache
- Try different browser

### Issue 7: "PDF generation failed"
**Solution:**
```
pip install --upgrade reportlab
```

### Issue 8: "Excel file corrupted"
**Solution:**
```
pip uninstall openpyxl
pip install openpyxl==3.0.9
```
